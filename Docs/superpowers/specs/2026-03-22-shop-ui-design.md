# Shop UI Design Specification

## Overview
The Shop UI allows players to interact with a Merchant NPC to purchase items. The shop displays a fixed set of items (3 slots) generated by the merchant.

## Architecture
- **UR1ShopWidget**: Main container for the shop interface.
  - Manages the overall layout (Background, Title, Close Button, Gold Display).
  - Holds and initializes the three `UR1ShopSlotWidget` instances.
- **UR1ShopSlotWidget**: Individual item display and interaction.
  - Displays item icon, name, rarity, and price.
  - Handles the "Buy" button click.
- **R1InventorySubsystem**: Backend logic for purchasing items and managing gold.
- **AR1MerchantNPC**: Provides the data (items for sale) to the Shop UI.

## Data Flow
1. **Trigger Shop**: Player interacts with `AR1MerchantNPC`.
2. **Open Shop**: `AR1MerchantNPC::OpenShop()` is called.
3. **Generate Items**: Items for sale are generated by the Merchant NPC based on the rarity probabilities.
4. **Buy Item**: Player clicks "Buy" on a `UR1ShopSlotWidget`. Calls `R1InventorySubsystem::BuyItem()`.
5. **Sell Item (Quantity Selection)**:
    - Player initiates a sell action from their inventory.
    - If the item is stackable (Consumable/Key) and has a quantity > 1, show `UR1SellQuantityPopup`.
    - User adjusts quantity using + and - buttons.
    - User confirms sell.
6. **Execute Sell**: Calls `R1InventorySubsystem::SellItem()` with the selected quantity.
7. **Feedback**: Gold is updated, and the item/quantity is removed from the inventory.

## Testing Strategy
1. **Populate Test**: Ensure the shop correctly displays the 3 items provided by the Merchant.
2. **Purchase Test (Success)**: Buy an item with sufficient gold and inventory space. Verify gold decreases and item appears in inventory.
3. **Purchase Test (Insufficient Gold)**: Attempt to buy an item without enough gold. Verify no purchase occurs.
4. **Purchase Test (Full Inventory)**: Attempt to buy an item with a full inventory. Verify no purchase occurs.
5. **Close Test**: Verify the shop UI closes correctly.
